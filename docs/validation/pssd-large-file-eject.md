# PSSD 大文件与双模式安全弹出回归

日期：2026-10-24。**当前状态：免 Root 大文件写入及安全弹出通过；重插后的持久性、Root 大文件和安全弹出仍待完成。**

## 环境与方法

- 小米平板 6SP，Android 16，无线 ADB；HIKSEMI P202 / RTL9210（0bda:9210）。未关闭 Wi-Fi。
- NTFS、exFAT、FAT32 各 CBC / XTS，共六卷。每卷只操作一个新建随机命名测试文件，每次写入 64MiB 随机数据，以完整长度和 SHA-256 核验。
- 从原 Root 六卷状态，经主页切换到免 Root；实际路径确认为 `usb://`，48 条保存凭据及附属记录哈希一致。
- 初始平板包 versionCode 134，Release 无 DEBUGGABLE；最终修复测试副本 versionCode 137 已准备，尚未安装。测试副本沿用设备已有签名以保留应用数据，不可作为正式发布附件。

## 免 Root 已通过

- 六卷各写入并回读 64MiB：NX 18.67、EX 21.02、EC 21.07、FC 21.12、FX 19.37、NC 20.14 秒。包括无线 ADB 推送、写入和回读，不是磁盘吞吐基准。
- NX 在 **309.84 秒**内重复覆写 **14 轮**，共 **896MiB**，每轮回读哈希一致；加上六卷首轮，共写入并校验 **1.25GiB**。重复阶段包含数据生成、传输和回读，不代表 310 秒全程都在向 USB 写入。
- 连续覆写后，六文件再次读取，长度及哈希一致。
- USB Host 授权监测 **546.27 秒、227 次采样**，没有授权丢失或意外进程重启。
- 通过 Provider `lock_volume` 调用主页使用的同一个 `safeEject` 实现，逐卷安全弹出。前五卷返回 `VOLUME_CLOSED_DISK_BUSY`，会话数逐次递减；最后一卷返回 `DISK_SPUN_DOWN`，最终会话数为 0，总耗时 **17.35 秒**。
- 日志确认进入 SYNCHRONIZE CACHE / START STOP UNIT 流程，没有停盘命令失败、新的 CSW 等待超时、批量写入错误或崩溃。没有主动复位、强制停止活动会话或重新扫描停盘设备。

## 检查中修复

`0aea8e1`：免 Root `spindownDevice` 过去在 START STOP UNIT 返回失败时只记录日志，仍可能返回成功。现改为返回失败，由已有界面显示卷已关闭但停盘失败，避免误报可以安全拔出。

99 项 Release JVM 测试、三架构 Release 构建和 lintVitalRelease 通过。此次尚未向真实 PSSD 注入停盘失败；不能把正常停盘成功的测试当作失败分支的设备验证。
