# SMART 数据来源与 SATA 参考解释

日期：2026-10-24。代码提交：`f25c595`（SATA 推算修正）、`3ce6790`（来源标注）。

## 实现

- 原始表新增 `Src`：`R` 为设备原始页，`S` 为摘要直接字段，`D` 为摘要换算，`U` 为未知或未提供。界面和复制文本均包含说明，来源不等于健康等级。
- 完整原始页优先于摘要；NVMe 原始温度未提供时，不用摘要覆盖。没有原始页时，摄氏度换算 Kelvin 标为 `D`；健康度为 0 时不能精确反推已用寿命，保持未知。
- 没有原始页的读写字节总量只有能被 512000 整除时才反推数据单位，标为 `D`；不再向下取整。其余摘要计数标为 `S`，不冒充原始页数据。
- ATA 表保留真实属性及原始值，缺失的常见属性以未知占位。摘要不再合成 E7、F1、F2 等厂商属性；名称仅作常见约定参考。
- 当前没有已验证的 SATA 型号配置，不再将 E7/A9/B1/E8 统一解释为剩余寿命，也不再将 F1 统一乘 512 得到字节数。这些摘要字段保持 `null`，原始属性不丢弃。
- SATA 常见累计错误计数出现正值时提示警告，不直接判定当前严重故障；零计数不足以证明整体健康，保持待确认。没有新增设备命令或恢复动作。

依据：[Kingston 的 SATA SMART 文档](https://media.kingston.com/support/pdf/phison-smart-attribute.pdf)中，A9 为坏块比例、E8 为读取失败计数，F1/F2 按 GB 计数，说明这些属性不能套用单一通用解释。其他常见属性的摘要仍需结合型号确认，界面已显示参考说明。

关键文件：`SmartHealthInfo.kt`、`SmartHealthDialog.kt`、中英文 `strings.xml`、`native/daemon/smart_reader.c`。
