# RTL9210 USB 驱动交接验证

## 范围

2026-10-23，小米平板 6SP（24018RPACC），HIKSEMI P202 / RTL9210
（USB 0bda:9210），6 个已保存凭据的 BitLocker 卷。

原问题发生在免 Root 的 BOT 接口交回内核 UAS 驱动时：内核首次 INQUIRY
超时，可能进入错误恢复或将设备离线。已有复现需要约 35 秒及两次错误恢复；
仅取消 STOP UNIT 的对照实验仍会失败，不能将停盘认定为唯一原因。

## 实现

- 仅在用户从免 Root 切换到 Root、当前仅有一个已识别的 USB 存储连接，且
  0bda:9210 暴露 UAS alternate 时采用此路径。其他设备沿用原有流程。
- 切换屏障排空扫描与解锁；安全关闭所有卷并确认没有 USB worker 后，执行
  SYNCHRONIZE CACHE。任何失败均阻止复位和模式更新。
- 在 usbfs 仍持有 BOT 接口时仅复位该设备，再关闭连接交回内核。此路径不发送
  STOP UNIT，也不删除 SCSI 节点。
- 设备复位可能已重新连接内核驱动，使旧接口 claim 失效。因此复位成功后仍关闭
  连接，但不把 releaseInterface 返回 false 单独视为交接失败。

## 2026-10-23 已验证事实

- 经用户明确授权，实际仅执行了 **1 次**设备复位；原生日志确认完成。
- 复位后内核重新绑定 UAS，并建立 PSSD 的 6 个加密分区；未观察到新的
  UAS 中止或错误恢复复位。
- 首次交接被过严的 releaseInterface 检查拦截，模式偏好保持免 Root；随后修正
  该检查，使用已恢复的内核状态安装最终包并恢复原有 Root/自动解锁设置。
- 最终包启动后约 **8.9 秒**出现 6 个 `/dev/block/` 会话，6 个卷的目录均可读取。
  保存凭据及附属记录保持一致，Wi-Fi 保持开启。
- 76 项 JVM 测试及 debug APK 构建通过，包含未知桥接芯片和仅 BOT 设备不复位的策略测试。

## 验证边界

上述初次验证在修正释放检查后未再执行第二次物理复位，尚未覆盖最终版本的完整界面往返；后续补测见下。
本次结果仅覆盖上述设备组合，不代表所有 RTL9210 固件均已验证。

后续判断 Root 解锁成功时，须同时核对模式偏好、会话路径为 `/dev/block/`，
以及目录读取成功；只统计 6 个已打开卷会把仍运行于 USB Host 的会话误判为 Root。

## 2026-10-24 补测

- 最终 Release 经主页触发免 Root → Root，应用重启后模式偏好为 Root，六个 `/dev/block/` 会话恢复、目录可读取，保存凭据及附属条目哈希一致。
- 临时关闭写入流水线的对照中，完成无人工重插的 Root → 免 Root → Root；EX 分区 2MiB 写入跨会话校验一致，后续 Root 六卷正常弹出通过。
- 默认异步配置另有真实的免 Root EX 写入失败，不能将驱动交接补测通过等同于整版可发布。完整证据与已恢复状态见 [PSSD 发布前回归](pssd-release-gate.md)。

- 后续 `74cf4ec` Release 已移除 USB 提前 ACK 路径，Root → 免 Root 六卷恢复及回读通过；NX 覆写仍在 CSW 阶段失败，后续往返已停止。写入异常尚未解决，仍不能发版，详见上述回归记录末节。


## 2026-10-24 后续修复复测

`0d939a2` 将所有模式切换改为同步并关闭卷、保持磁盘在线；已验证 RTL9210 的免 Root → Root 专用交接复位保留。用户主动安全弹出的停盘、磁盘脱机和同盘占用检查没有移除。此前“其他设备沿用原有流程”的描述对应旧版本，当前其他路径同样不在模式切换时停盘。

最终逻辑 Release（versionCode 134）冷插入后，六卷免 Root 写入与 NX 重复覆写通过。随后从主页完成免 Root → Root → 免 Root → Root，无人工重插、额外授权或凭据丢失；每次核验实际后端、六卷文件哈希。切回免 Root 后再次六卷覆写及约 203 秒持续检查通过，最终恢复 Root 六卷并清理测试文件。

这些结果支持当前交接流程，但不能据此将此前 CSW 超时全部归于 STOP UNIT，也不能代表所有桥接固件。完整分阶段结果、失败历史和验证边界见 [PSSD 发布前回归](pssd-release-gate.md)。


大文件后续补测也已完成：双模式六卷各 64MiB 写入、免 Root 约 310 秒连续覆写、正常安全弹出和物理重插持久性均通过；最终保留原 Root 六卷。详细范围与版本见 [大文件与双模式安全弹出回归](pssd-large-file-eject.md)。
