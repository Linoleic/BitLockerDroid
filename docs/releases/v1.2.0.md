# v1.2.0

## 中文

### 新增与改进

- 主页统一“连接与授权”，集中管理 Root / 免 Root 模式、授权状态和 Root 环境。
- 磁盘健康显示查询时间、耗时、失败阶段和数据校验结果；原始表标明数据来源，保留完整计数并修正列对齐。
- 优化窄屏和短横屏的标题、操作按钮及弹窗滚动。

### 安全与修复

- 统一解锁、文件访问及凭据查看的生物识别授权规则，修复取消验证时的崩溃。
- 修复免 Root 写入、模式切换和会话复用问题；写入或同步失败时阻止弹出，停盘失败时明确提示。
- 模式切换同步关闭卷并保持磁盘在线，安全弹出保留停盘保护。
- S.M.A.R.T. 查询失败或缺失指标保持“待确认 / 未知”，不再推算未经验证的 SATA 寿命或阈值。

### 使用说明与验证范围

- 免 Root S.M.A.R.T. 查询需先关闭该设备上的全部卷，避免干扰读写；未知 USB 桥接芯片不会发送专用探测命令。
- Root 模式自动过滤已确认 BitLocker 卷的系统修复提示，其他通知不在该过滤规则内。
- 已在小米平板 6SP、RTL9210 NVMe PSSD 上验证双模式六卷读写、模式切换、安全弹出及重插持久性。SATA 实盘及其他桥接设备尚未完成验收。
- 低分辨率已通过平板模拟复测；短横屏需滚动查看详情，不代表所有设备和字体设置均已覆盖。

### 附件

- **`app-release.apk`：日常使用请选择此版本。**
- `app-debug.apk`：用于调试和排查问题；调试开销可能使主页滚动更慢，请使用 Release 包评估实际性能。
- `checksums.txt`：两个 APK 的 SHA-256 校验值。

## English

### Added and changed

- Manage Root / non-root mode, authorization status, and Root environment details in one home connection panel.
- Show query time, duration, failure stage, and data validation in Disk Health. Label raw-value sources, preserve full counters, and align table columns.
- Improve titles, action buttons, and dialog scrolling on narrow and short landscape screens.

### Security and fixes

- Apply biometric authorization consistently to unlocking, file access, and saved credentials; fix a crash when authentication is cancelled.
- Fix non-root writes, mode transitions, and session reuse. Block ejects on unfinished writes or failed flushes, and report spindown failures.
- Flush and close volumes during mode changes while keeping the disk online; retain spindown protection for explicit ejects.
- Keep failed S.M.A.R.T. queries and missing metrics unconfirmed or unknown; do not infer unverified SATA lifetime or thresholds.

### Usage and validation scope

- Close all volumes on a device before a non-root S.M.A.R.T. query. No vendor probe commands are sent to unknown USB bridges.
- Root mode automatically filters verified BitLocker repair prompts; other notifications fall outside this rule.
- Dual-mode six-volume I/O, mode changes, safe eject, and persistence after reconnection were tested on a Xiaomi Pad 6SP with an RTL9210 NVMe PSSD. Physical SATA drives and other bridges remain unverified.
- Low-resolution layouts were tested through tablet display overrides. Short landscape windows require scrolling; coverage does not include every device or font setting.

### Assets

- **`app-release.apk`: recommended for everyday use.**
- `app-debug.apk`: for debugging and troubleshooting. Debug overhead may make home scrolling slower; use Release to assess performance.
- `checksums.txt`: SHA-256 checksums for both APKs.
